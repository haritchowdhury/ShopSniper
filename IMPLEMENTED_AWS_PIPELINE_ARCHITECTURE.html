Cross-cutting rails carried through every canvas

IMMUTABLE CONTEXTrun ID + generation + expected item set · manifest key + manifest fingerprint + producedAt · task input fingerprints + frozen provider configuration · follows registration through final validation
WORKER COMMIT ORDERclaim fenced lease → execute only frozen missing work → write and validate immutable S3 artifact → record first Neon terminal transition → send aggregation check → acknowledge original SQS record last
COMPLETIONNeon terminalCount must equal immutable expectedCount; then one aggregator validates every expected task and artifact. Queue emptiness, S3 counts and S3 events never complete a stage.
DELIVERYsix SQS queues provide at-least-once delivery, partial batch failure, retry, backpressure and DLQ routing. Duplicate, delayed, split and reverse delivery are expected.
RECOVERYLambda 7 scans only known expired Neon work, recreates exact versioned work/check messages and re-enters the normal fenced queue path. Stale unknown paid DataForSEO work becomes ambiguous.
CANCELLATIONatomic generation cancellation terminalizes pending work, invalidates lease tokens and rejects every late worker or publication write
